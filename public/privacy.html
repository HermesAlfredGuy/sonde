Privacy

Last updated 12 September 2026

Sonde is a fictional product built as a design study, and this page exists to show how the real thing would read. It describes the data handling of a database agent that runs inside an operator's own network.

What we collect

A work email when you book a walkthrough, and the pages you visit on this site. No advertising identifiers, no third party analytics scripts.

What the agent touches

Schema names, table and column metadata, the question you ask, the SQL the agent writes, and the row counts returned. Row data stays in your network unless you switch on row context for a specific run.

Retention

Query logs are kept for 90 days by default and can be exported at any point. Walkthrough requests are deleted after 12 months.
