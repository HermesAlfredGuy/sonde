Privacy

Last updated 26 October 2026 · concept study

This page collects nothing. There is no account, no form, no cookie, no analytics script and no third-party request of any kind.

What is measured

Nothing. The demo, the animations and the artwork all run inside your browser. The three wells, the SQL and every number are invented on the device; no request leaves the page except the files that make it up, all served from this site.

What a real product would keep

For the record, because the page argues about provenance: a run log would hold the question, the generated SQL, the tables read, the row count, the elapsed time and the name of the approver. It would be exportable and deletable, and the design keeps row data out of the agent unless a named person switches it on for one run.

Hosting

This site is static files on GitHub Pages. GitHub records standard request logs, including IP addresses, as any web host does. There is no tracking on top of that, and no advertising identifier.

Fonts and images

Geist is self-hosted from this site under the SIL Open Font License. The rock texture composited into the artwork is by Poly Haven, CC0, also self-hosted. No font or image CDN is contacted.
